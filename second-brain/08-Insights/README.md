# Insights

Distilled knowledge extracted from clusters of session notes — structured reference notes that outlive any single session.

## When to create an insight
- You've written 3+ session notes on the same topic
- You spot a recurring pattern or decision across sessions
- You want to upgrade a session learning into a permanent reference

## Naming convention
```
YYYY-MM-DD-[topic-slug].md
```

## Template
Use [[05-Templates/insight]] when writing a new insight note.

## Reading insights
Insights live here permanently and supplement [[03-Resources/]] notes.
Agents should prefer referencing insights over raw session notes when answering questions.
