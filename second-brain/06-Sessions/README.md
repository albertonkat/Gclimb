# Sessions

All agent session summaries live here — one file per session, written at the end of every conversation.

## Naming convention
```
YYYY-MM-DD-[agent]-[topic-slug].md
```
Examples:
- `2026-06-08-claude-second-brain-setup.md`
- `2026-06-09-hermes-zwave-device-handler.md`

## Template
Use [[05-Templates/session-capture]] when writing a new session note.

## Reading sessions
When starting a new session, agents should scan the last 3 entries here for context continuity.
