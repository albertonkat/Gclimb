# Clinical Practice — Overview

Standards, workflows, and documentation requirements for Gulf Coast Limb and Brace.

---

## SOAP Note Structure for O&P

### S — Subjective
- Chief complaint and reason for visit (initial fit, adjustment, replacement, follow-up)
- Patient-reported functional limitations and goals
- Pain with current device (location, onset, character, 0–10 scale)
- Activity level and lifestyle demands (informs K-level)
- Prior prosthetic/orthotic history (devices, outcomes)
- Relevant medical history: comorbidities, medications, recent hospitalizations

### O — Objective
- **Residual limb / affected anatomy:**
  - Skin integrity: color, turgor, breakdown, pressure areas, scars
  - Limb shape, volume stability, atrophy/edema
  - Circumferential measurements (document sites: e.g., 3cm, 6cm, 9cm from distal end)
  - ROM: hip flexion/extension/abduction, knee flexion/extension
  - Muscle strength (manual muscle test grades 0–5)
- **Current device:**
  - Make, model, componentry (foot, knee, socket type)
  - Condition (socket, liner, components)
  - Fit assessment: pistoning, suspension, pressure areas
- **Gait/function assessment:**
  - Gait deviations observed (list specific deviations)
  - Assistive device use
  - Walking speed and distance (TUG test, 6MWT if performed)
  - Stair negotiation, ramp, uneven terrain ability

### A — Assessment
- Primary ICD-10 diagnosis (e.g., Z89.511 — acquired absence right leg below knee)
- Secondary diagnoses (etiology: E11.x diabetes, I70.x PAD, S72.x trauma)
- **K-level functional classification** with clinical justification
  - K0: Not appropriate for prosthesis
  - K1: Household ambulator only — limited distance, no variable terrain
  - K2: Limited community — can handle low-level barriers
  - K3: Community ambulator — variable cadence, most environments
  - K4: High activity — exceeds basic ambulation, high impact/stress demands
- Medical necessity statement: why the device/service is required
- Device assessment: fit, function, condition, need for modification or replacement

### P — Plan
- Device prescription with **HCPCS L-codes** (be specific — include all components billed)
- Fabrication timeline
- Delivery target date
- Follow-up schedule
- Patient education provided
- Referrals (PT, MD, wound care) if indicated

## Documentation Requirements (Medicare Standard)

Medicare requires documentation to support **medical necessity**. Missing any of these is a common denial reason:

| Required element | Where documented |
|---|---|
| Physician order/prescription | In patient chart; must be signed, dated, within 12 months |
| Face-to-face exam | SOAP note — must show CPO performed the exam |
| Diagnosis (ICD-10) | SOAP note and claim |
| Functional classification (K-level) | SOAP note — must state level AND clinical rationale |
| Failure of conservative treatment | SOAP note — for orthotics especially |
| Device specification (HCPCS) | SOAP note and delivery receipt |
| Patient consent/ABN (if applicable) | Signed ABN when coverage uncertain |

## Common Visit Types

| Visit type | Note focus |
|---|---|
| **Initial evaluation** | Full H&P, K-level determination, device recommendation |
| **Fitting** | Measurements, socket assessment, initial gait |
| **Delivery** | Device description, fit assessment, patient education, gait training |
| **Follow-up / adjustment** | Problem, exam finding, modification made, outcome |
| **Annual re-evaluation** | Current device status, continued medical necessity, updated goals |
| **Replacement evaluation** | Documented reason for replacement (wear, fit change, functional need) |
