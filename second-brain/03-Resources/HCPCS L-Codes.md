# HCPCS L-Codes — O&P Billing Reference

HCPCS Level II L-codes are used to bill prosthetic and orthotic devices under Medicare Part B DMEPOS and most commercial payers.

---

## Common Code Pairings (Diagnosis + Device)

| Diagnosis | Typical HCPCS |
|---|---|
| BK amputee, K3 | L5301, L5620, L5679, appropriate foot (L5981) |
| AK amputee, K3 | L5200/L5301 (AK), L5857 (MPK if K3 justified), L5987 |
| Foot drop (CVA/MS) | L1940 or L1960 (solid AFO) |
| Diabetic Charcot foot | L1940 or L1971 (rigid AFO), L3000-series inserts |
| ACL injury | L1820 (custom derotation KO) |
| Lumbar stenosis/compression | L0640 (custom LSO) |
| Scoliosis | L1000 TLSO Milwaukee-style or L0456 |
